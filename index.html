▶ দেখো
  
  
  
প্রথমে নিচের Settings থেকে Firebase ও YouTube API কনফিগার করুন। কনফিগার না করলেও নমুনা ফিড ও লোকাল ফিচার দেখা যাবে।
  
                                     
  
    

তোমার জন্য

    
কমিউনিটির ভিডিও Firestore থেকে লোড হবে। ভিডিও আপলোড/স্টোরেজ এই সংস্করণে যুক্ত করা হয়নি।
    
  
  
    

YouTube ভিডিও সার্চ

    
    
YouTube API key বসাতে Settings খুলুন। API কেবল YouTube-এর অনুমোদিত তথ্য/ভিডিও দেখায়।
